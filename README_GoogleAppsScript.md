## ⚙️ STEP 2: Deploy Google Apps Script Web App

1. In your **`Swarajya Infotech Website Leads`** Google Sheet, click **Extensions &rarr; Apps Script** in the top menu bar.
2. Delete any default code in `Code.gs`.
3. Copy the entire contents of [`google_apps_script/Code.gs`](file:///e:/web/google_apps_script/Code.gs) and paste it into the editor.
4. Click the 💾 **Save project** icon (or press `Ctrl + S`).
5. Click **Deploy &rarr; New deployment** (top right blue button).
6. Click the ⚙️ gear icon next to "Select type" and select **Web app**.
7. Configure the deployment settings:
   - **Description**: `Swarajya Infotech Web Lead Capture API`
   - **Execute as**: **`Me (prasadnimbalkar2555@gmail.com)`**
   - **Who has access**: **`Anyone`** *(Crucial: allows public form submissions from your website)*
8. Click **Deploy**.
9. Click **Authorize access** when prompted, select `prasadnimbalkar2555@gmail.com`, click **Advanced &rarr; Go to Swarajya Infotech Web Lead Capture API (unsafe)**, and click **Allow**.
10. Copy the generated **Web App URL**.  
    *Example:* `https://script.google.com/macros/s/AKfycbx.../exec`

---

## 🔗 STEP 3: Link Web App URL to Website

1. Open [`assets/js/custom.js`](file:///e:/web/assets/js/custom.js) in your codebase.
2. Locate line 7:
   ```javascript
   const GOOGLE_SCRIPT_WEB_APP_URL = "YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";
   ```
3. Replace `"YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE"` with your actual Web App URL copied in Step 2.
4. Save the file and push your updates to **GitHub Pages**.
